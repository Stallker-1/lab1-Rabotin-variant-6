# Лабораторная работа №1 — Основы машинного обучения и предобработка данных

**Вариант 6 — Wholesale customers (кластеризация)**

## Цель работы

Получить практический опыт предобработки данных и кластеризации клиентов
с помощью K-Means, иерархической кластеризации и DBSCAN, оценить качество
моделей и интерпретировать полученные сегменты.

## Используемый датасет

**Wholesale customers** — годовые расходы клиентов оптового дистрибьютора
на различные категории товаров.

- Источник: UCI Machine Learning Repository, ID 292
- Ссылка: https://archive.ics.uci.edu/dataset/292/wholesale+customers
- Лицензия: CC BY 4.0
- Размер: 440 объектов, 8 признаков
- Целевая переменная: отсутствует (задача кластеризации)

Файл данных `Wholesale customers data.csv` не коммитится в репозиторий
(см. `.gitignore`). Скачайте его вручную и положите рядом с ноутбуком.
